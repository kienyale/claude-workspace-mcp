Claude Workspace MCP

A personal tool used by Kien Lau only. It lets Kien's own AI coding assistants (Claude) read and edit Kien's own Google Docs, Drive, Sheets, Slides, Gmail drafts and Calendar through Google's APIs. It is not offered to anyone else.

Privacy policy

This app accesses only the Google account of the person who signs in to it, which is Kien Lau's own account.

  • Data from Google APIs is used only to carry out requests Kien makes to his own assistants.
  • OAuth tokens are stored only on Kien's own computers, in files readable only by his user account.
  • No data is sold, shared with third parties, or used for advertising.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
